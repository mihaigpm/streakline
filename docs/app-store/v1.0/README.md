# Streakline App Store submission package — v1.0

Draft package for App Store Connect submission of marketing version **1.0**
(build **1**).

## Package contents

- `metadata.md` — listing copy and URLs
- `review-notes.md` — App Review access and test path
- `app-privacy.md` — App Privacy questionnaire draft
- `compliance.md` — age-rating, content, and export-compliance guidance
- `accessibility.md` — accessibility declaration verification checklist
- `screenshots.md` — capture order and shot list
- `release-notes.md` — v1.0 release notes

## Before submission

All text is a concrete draft, but the submitter must verify it against the
archived binary and the current App Store Connect questionnaires. Replace every
`[CONFIRM ...]` item, upload final screenshots from the release build, verify
the support and privacy URLs are live, and answer Apple's age-rating and
accessibility questions from hands-on testing. Do not add an App Store or
TestFlight URL until Apple provides the real URL.
